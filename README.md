# Seguridad en Sistemas Operativos

Página web explicativa con cinco temas de la materia Sistemas Operativos:

1. Cómo dar seguridad a un sistema (nivel aplicación y nivel base de datos)
2. Copia de seguridad y restauración de una base de datos
3. Tendencias y avances en sistemas operativos
4. Amenazas externas (malware, phishing e ingeniería social, denegación de servicio, ransomware)
5. Detección y respuesta a incidentes de seguridad

## Uso

Abrir `index.html` en el navegador. No requiere instalación. Las fuentes se cargan desde Google Fonts, por lo que se necesita conexión a Internet para verlas; sin conexión se usan fuentes del sistema.

## Publicar con GitHub Pages

En el repositorio: Settings > Pages > Source: Deploy from a branch > rama `main`, carpeta `/ (root)`.
